## qa-test-case-generation

`src/skill-import.ts` implements a parser for the test-case table format
defined by `assets/default-test-case-template.md` and the Source tag
taxonomy (`Requirement` / `Mockup` / `Requirement + Mockup` / `Inferred QA
Risk`) defined by `SKILL.md`, from:

https://github.com/saleem-daqa/qa-test-case-generation

No files from that repository are vendored here; only the table schema and
Source tag names are referenced in code, as noted in `src/skill-import.ts`.
